# 神兽疗愈收容所 · 竖切片原型（H5）

## 合成疗愈竖切片（新增）

打开 `merge_slice.html` 可试玩新的合成主玩法竖切片：药圃生成材料 → 二合一 → 交付穷奇委托 → 自动进入庭院查看疗愈反馈。它与原有照料原型并列，不会覆盖旧入口；从项目根目录启动静态服务器可避免 `../art/` 资源路径失效：

```bash
python -m http.server 8080
```

然后访问 `http://localhost:8080/prototype/merge_slice.html`。

> 项目代号：小动物山海经。本目录同时保留一套旧版照料原型。
> 当前验收只针对 `merge_slice.html`；`index.html` 及其喂食/清洁面板是 legacy reference，不要与正式合成入口混用。

## 运行方式
- **正式入口**：访问 `merge_slice.html`（推荐通过项目根目录静态服务器打开）。
- **旧版参考**：`index.html` 仅用于查看历史照料原型，不代表当前玩法。
- **或静态服务器**（推荐，避免个别浏览器对 file:// 的严格限制）：
  ```bash
  cd prototype
  python3 -m http.server 8080
  # 浏览器打开 http://localhost:8080
  ```

## 当前正式循环
医馆五槽委托（主线 / 修缮 / 医案 / 访客 / 七日旅程）→ 7×7 棋盘拖动整理与二合一
→ 配方台制作配方成品（安神药包、灵木床等均有专用图片素材）→ 交付素材与成品推进疗愈
→ 宗门页修缮与扩张（14 区域舆图、雾锁解锁、区域永久加成、五幕卷章引擎）
→ 庭院建筑入口（梳洗台消消乐 / 嬉游亭羊了个羊）→ 有效照料推进病历 → 异兽蜕变与岗位产出
→ 离线结算、每日目标、七日约定与永久委托。

**零失败**：小游戏可跳过或超时，达到有效操作门槛仍有保底奖励；失败、超时、断线都不会丢失已到手的素材与进度。

**进入引导**：首次进入依次播放欢迎卡与四页玩法说明；所有主要模块和动态卡片都支持长按查看“干什么 / 需要什么 / 有什么用”。灵泡与宝箱模块已从竖切片移除。

## 操作
- 医馆棋盘：拖动素材到空格可整理，拖到同类同阶素材即可合成；长按素材查看路线、来源与当前用途；长按生成器查看掉落与升级。
- 配方：点“配方台”展开当前卷章配方；长按配方卡或配方柜成品查看图片、材料来源与用途。
- 宗门：幕一修缮交付合成素材，逐段点亮区域；点击舆图节点切换近景，雾锁区域长按/点击查看解锁条件。
- 庭院：点击梳洗台进入消消乐，点击嬉游亭进入羊了个羊；长按建筑查看该设施干什么、需要什么、有什么用。
- 底部栏：宗门、医馆、庭院、图鉴；辅助设施、岗位、背景和药匣均通过弹层打开。

## 已锁定数值（详见 data.js 注释）
- 蜕变阈值：`Trust ≥ 60`、`Heal ≥ 100`。
- 四类基础产出（GDD §0 表）：喂食(4,3) / 清洁(4,3) / 梳毛(5,4) / 陪玩(8,5)。
- 匹配倍率：对症 ×1.5，非对症 ×0.5（始终正）。
- `EnvBonus = 1 + 0.05 × 设施等级`；`DailyStreakBonus = min(1 + 0.02 × 连续天数, 1.20)`。
- 经济：暖玉初始 0；蜕变 +20 暖玉；上岗神兽每日 +2 食材；喂食耗 1 食材（无食材→温柔禁用）。
- 三人组：穷奇(A·陪玩) / 九尾狐(B·梳毛) / 饕餮(G·陪玩+喂食)。

## 美术说明
- 直接引用 `../art/` 下的真实 PNG（穷奇/九尾狐 疗愈后、治愈庭院），未复制图片。
- 疗愈前（INTAKE/SYMPTOMATIC/HEALING）**复用疗愈后 PNG + 生病滤镜**（灰度+褐调+微暗+轻摆）；
  蜕变后（TRANSFORMED/WORKING）还原全彩。图片加载失败时有可爱占位兜底。

## 存档
- 自动存入 `localStorage`（JSON + 轻量校验和），刷新/重开自动读档；「重置」清档。
- 离线按日期温和结算（每日 streak +1、上岗神兽产食材，上限 30 天）。

## 已知假设 / 待主理人确认
1. **照料基础数值**：采用 GDD §0 示例表（喂食4/3、清洁4/3、梳毛5/4、陪玩8/5），可满足「约 8–15 次对症照料蜕变」。
   任务简报「例如」另一组数值（清洁3/5、梳毛5/3、陪玩6/2）会使蜕变需约 22–32 次，与 8–15 目标冲突且不同于 GDD §0，未采用。
2. **食材初始缓冲 = 5**（便于首会话即体验喂食）；如需严格「无食材即禁用」可设 0。
3. **暖玉初始 0**（按简报；GDD §4 示例为 50）。
4. 羁绊增长在完整版由共处/协作/送礼/共委托驱动；本期以「双方均蜕变」作为可演示触发条件。
5. 三人组内仅 穷奇×九尾狐 可触发合体线（其余羁绊随 12 兽阵容扩展解锁；相柳已移除）。
