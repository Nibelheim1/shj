# 神兽疗愈收容所 · 竖切片原型（H5）

## 合成疗愈竖切片（新增）

打开 `merge_slice.html` 可试玩新的合成主玩法竖切片：药圃生成材料 → 二合一 → 交付穷奇委托 → 自动进入庭院查看疗愈反馈。它与原有照料原型并列，不会覆盖旧入口；从项目根目录启动静态服务器可避免 `../art/` 资源路径失效：

```bash
python -m http.server 8080
```

然后访问 `http://localhost:8080/prototype/merge_slice.html`。

> 项目代号：小动物山海经。本原型是《神兽疗愈收容所》Phase 1 最小可玩闭环的可运行验证，
> 引擎无关核心逻辑 + 全局脚本模式 H5，双击 `index.html` 即可运行（无需构建、无 ES module、无 fetch）。

## 运行方式
- **最简单**：直接双击 `index.html`（file:// 下可运行；图片与存档均本地，无跨域请求）。
- **或静态服务器**（推荐，避免个别浏览器对 file:// 的严格限制）：
  ```bash
  cd prototype
  python3 -m http.server 8080
  # 浏览器打开 http://localhost:8080
  ```

## 核心循环（与 GDD §0 一致）
收容（委托接兽）→ 评估（创伤档案叙事）→ 照料（喂食/清洁/梳毛/陪玩四类，对症矩阵结算）
→ 疗愈（Trust/Heal 双轨）→ 蜕变（Trust≥60 且 Heal≥100）→ 图鉴（前后对比）
→ 经济（暖玉 + 食材闭环：上岗神兽产食材 / 喂食消耗食材）。

**零失败**：任何互动都给正向反馈，无惩罚、无倒计时。

## 操作
- 点击庭院里的神兽 → 打开照料面板。
- 底部栏：🐾收容（接新兽）、📖图鉴、💞羁绊、🌅新的一天（推进日期/产出食材，便于体验经济闭环）、↺重置（清档重来）。
- 首次进入会引导你接第一只神兽回家。

## 已锁定数值（详见 data.js 注释）
- 蜕变阈值：`Trust ≥ 60`、`Heal ≥ 100`。
- 四类基础产出（GDD §0 表）：喂食(4,3) / 清洁(4,3) / 梳毛(5,4) / 陪玩(8,5)。
- 匹配倍率：对症 ×1.5，非对症 ×0.5（始终正）。
- `EnvBonus = 1 + 0.05 × 设施等级`；`DailyStreakBonus = min(1 + 0.02 × 连续天数, 1.20)`。
- 经济：暖玉初始 0；蜕变 +20 暖玉；上岗神兽每日 +2 食材；喂食耗 1 食材（无食材→温柔禁用）。
- 三人组：穷奇(A·陪玩) / 九尾狐(B·梳毛) / 相柳(C·陪玩+清洁)。

## 美术说明
- 直接引用 `../art/` 下的真实 PNG（穷奇/九尾狐/相柳 疗愈后、治愈庭院），未复制图片。
- 疗愈前（INTAKE/SYMPTOMATIC/HEALING）**复用疗愈后 PNG + 生病滤镜**（灰度+褐调+微暗+轻摆）；
  蜕变后（TRANSFORMED/WORKING）还原全彩。图片加载失败时有可爱占位兜底。

## 存档
- 自动存入 `localStorage`（JSON + 轻量校验和），刷新/重开自动读档；「重置」清档。
- 离线按日期温和结算（每日 streak +1、上岗神兽产食材，上限 30 天）。

## 已知假设 / 待主理人确认
1. **照料基础数值**：采用 GDD §0 示例表（喂食4/3、清洁4/3、梳毛5/4、陪玩8/5），可满足「约 8–15 次对症照料蜕变」。
   任务简报「例如」另一组数值（清洁3/5、梳毛5/3、陪玩6/2）会使蜕变需约 22–32 次，与 8–15 目标冲突且不同于 GDD §0，未采用。
2. **食材初始缓冲 = 5**（便于首会话即体验喂食）；如需严格「无食材即禁用」可设 0。
3. **暖玉初始 0**（按简报；GDD §4 示例为 50）。
4. 羁绊增长在完整版由共处/协作/送礼/共委托驱动；本期以「双方均蜕变」作为可演示触发条件。
5. 相柳的叙事羁绊①（与饕餮）不在本期三人组内，故 trio 内仅 穷奇×九尾狐 可触发合体线。
