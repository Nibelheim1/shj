# 神兽揭示演出文案 v6

## 穷奇

| 时机 | 玩家可见短文案 / 小秘密 |
| --- | --- |
| Lv1 获得 | 门后那只小怂虎探出耳朵：我可以陪你看门吗？ |
| Lv1→Lv2 | 穷奇往前挪半步，小声宣布：今天我守你身边。 |
| Lv2→Lv3 | 雨声一响，穷奇举起小伞：别怕，我记得回家的路。 |
| Lv3→Lv4 | 它把门灯擦得亮亮的：晚归的人，我一个也不漏。 |
| Lv4→Lv5 | 穷奇甩甩翅膀：这扇门有我，安心把烦恼放下吧。 |

## 九尾狐

| 时机 | 玩家可见短文案 / 小秘密 |
| --- | --- |
| Lv1 获得 | 九尾狐捧着一条软尾巴报到：请把害羞藏在我身后。 |
| Lv1→Lv2 | 一条尾巴变三条，九尾狐说：今天的风有三种香气。 |
| Lv2→Lv3 | 五尾展开像花扇：镜子借你，我也要学着看自己。 |
| Lv3→Lv4 | 七盏狐灯随尾尖亮起：晚归的朋友，别怕迷路啦。 |
| Lv4→Lv5 | 九尾齐齐开屏，青丘的风把庭院吹成会笑的云。 |
