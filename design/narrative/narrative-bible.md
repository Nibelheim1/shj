## 1. 一句话定位

> 末法时代，灵气稀薄。你继任栖霞宗掌门，把散落的天材地宝合成灵气，把荒废的宗门一盏盏修亮，再把那些落魄的神兽，一只只等回家。

**游戏标语（主）**：山海倦了，家还亮着。
**备用标语**：
- 把往日的风采，轻轻找回来。
- 这里没有凶兽，只有还没等到家的人。
- 山海很远，栖霞很近。

## 2. 世界观三层

### 上古：各有各的灯火
山海界灵气充沛，神兽各守天职——虎踞山门、狐守青丘、龙烛照夜、鲲鹏行云。栖霞宗以温柔之道照料万物，檐下十二盏归灯长明，人兽两界安宁。

### 变故：灵气稀薄，山海打了个盹
末法时代来临，灵气日渐稀薄。神兽失去滋养，一只只"落魄"下来：尾巴不蓬了、火苗点不着了、夜里发不出光了、心气也散了。宗门守不住灵气，渐渐荒废。

**没有敌人，没有灾祸，没有恐怖。** 灵气不是被夺走的，只是"睡着了"。这是一场漫长而温和的力不从心。

### 如今：掌门继任
你推开山门，门后传来一声轻轻的、紧张的呼噜。从那天起，你是栖霞宗的新任掌门。

## 3. 核心叙事装置：归灯

- **十二只神兽 = 十二盏归灯。** 宗门页/主线界面顶部建议常驻十二盏灯的进度条：点亮一盏，就多一位家人回家。
- **灯信** = 现有玩法的礼赠链：上一只神兽蜕变后，留下一件心意之物（九尾手镜、嬉云糖塔……），它是下一只神兽的邀请函，也是它自己的成长见证。**心意会认路。**
- **灵力** = 掌门白日攒下的灯油，慢慢蓄，不催促。
- **合成** = 天材地宝散成了碎片，两两相认，灵气归位。
- **修缮** = 重新点亮宗门的灵气回路；每一个区域变亮，庭院就更暖一分。
- **疗愈** = 帮一只神兽重新相信自己值得被等。

**长线悬念（软萌、不恐怖）**：灯台最底一行没有名字。随着卷章推进，旧信、旧物、访客的只言片语会慢慢拼出答案——原来山海没有忘记谁，它只是太累了，一直在等有人先回来。终卷答案落在鲲鹏的云海。

## 4. 玩家身份

- 正式称呼：**掌门**。
- 神兽可亲昵地叫"小掌门""掌门掌门"；访客正式地叫"栖霞宗主"；系统卷册只用"掌门"。
- 掌门不是救世主，是"记得回来开门的人"。文案不写"拯救/使命/天赋异禀"，写**陪伴、等待、把日子过回来**。

## 5. 卷章结构：十二卷五幕

每卷统一五幕，是合成目标、剧情、元目标三合一载体：

| 幕 | 名称 | 玩法落点 | 叙事功能 |
|---|---|---|---|
| 幕一 | 修缮 | 区域 3 段修缮委托 + 合成 | 让"家"先亮起来 |
| 幕二 | 收容 | 信物合成 + 新兽来信 | 让"它"愿意进来 |
| 幕三 | 疗愈 | 3 步医案 + 照料小游戏 | 让"心"重新鼓起来 |

卷终固定三件套：**山海册新页 + 灯信发光 + 下一卷钩子**。

## 7. 三钩公式（期待感引擎）

**短钩（15 秒）**：每完成一次交付/合成里程碑，回一句"世界变化"。
格式：`对象 + 动作 + 感官细节 + 一点点变化`
例："门灯亮了。风先钻进来，把门后的小影子照暖了一下。"

**中钩（一日/一幕）**：每幕收口，先总结变化，再预告下一件小事。
格式：`已经发生的 + 所以接下来 + 一句鼓励`
例："药炉温了，它敢在灯下多待一会儿了。下一步，去庭院陪它玩一场。"

**长钩（一卷）**：卷终 = 灯信发光 + 新神兽线索 + 山海册新页。
格式：`物件发亮 + 感官线索 + 下一卷名`
例："包袱里的小镜子忽然亮了。不是月光——是青丘有九条尾巴，把风都梳成了信。下一卷：九尾狐篇。"

## 9. 文案写作规范

### 9.1 三条红线
1. **形貌可引、凶行不引**：古籍只摘温和的形貌/神性描写，不写凶残、恐怖、血、伤情惨烈。
2. **零失败语气**：不出现"失败/惩罚/扣/必须/否则"；改写成"没做完也没关系，它会等你"。
3. **不卖惨**：不说"可怜/没人要/废物"；落魄的表现是"蔫一点、毛塌一点、躲在门后"，落脚点永远是"它值得被好好对待"。

### 9.2 长度规范
| 位置 | 上限 |
|---|---|
| 气泡 / toast / 按钮 | 24 字 |
| 委托正文 / 交付反馈 | 32 字 |
| 卷首实录 / 图鉴故事 | 60 字 |
| 卷终钩子 | 40 字 |
| 玩法说明单条 | 60 字 |

### 9.3 句式配方
**角色故事句**：从前的它（一句）+ 现在的小落魄（一句）+ 它真正想要什么（一句）。
**世界变化句**：你做了什么 + 哪里变好了 + 一个可感知的细节。
**引导句**：先去哪里 + 做什么 + 为什么这件事会让世界变好。

### 9.4 用词偏好
- 用"灵气、光、风、水声、毛的触感、饭香、灯"等感官词；
- 动词偏软：等、陪、梳、摆、收、点亮、修；
- 少用：战斗、击败、镇压、治疗（可用"疗愈/照料"替代）、解锁（可用"灵雾散开/寻到"）。
