# 异兽角色阵容（Beast Cast）

**说明**：12 个脍炙人口的山海经 / 东方传说形象，全部"转化"为可爱小动物（或温和的威严相）。世界观为**末法时代·灵气稀薄**：神兽们失去灵气滋养，纷纷"落魄"——毛塌、蔫蔫的、本领失灵，但**自始至终可爱，绝无恐怖/凶恶形态**。前 9 只（穷奇 / 九尾狐 / 饕餮 / 帝江 / 毕方 / 白泽 / 梼杌 / 烛龙 / 貔貅）为"灵兽 / 威严兽"，字段含"疗愈前症状（= 落魄表现）"；后 3 只（麒麟 / 凤凰 / 鲲鹏）为"祥瑞吉兽"，字段改为"初来状态（祥瑞的落魄小烦恼）"。疗愈 = 温养灵气；蜕变 = 重焕精神。每个含：本相与出处、落魄由来、可爱化设定、疗愈前症状/初来状态、疗愈后蜕变、视觉关键词。
> **Erratum（2026-08）**：相柳已从正式阵容移除（见 `design/gdd/gdd-major-update-sect.md` 附录 C）；"恐怖传说 / 浊气扭曲"框架废止，反差萌改为「昔日神骏 ↔ 今日落魄软萌 ↔ 焕新」。

### 1. 穷奇 · 门后怂包守卫
- **本相 & 出处**：《山海经·海内北经》"穷奇状如虎，有翼"——有翼虎形的巡山灵兽，本该威风凛凛守着山门。
- **落魄由来**：末法时代灵气稀薄，翅膀没力气扑腾，威风不起来，只敢躲在门后露一只耳朵。
- **可爱化设定**：胖乎乎的带翅小虎崽，短圆飞翼扑腾不起来。性格：**护短、慢热、外凶内怂**。职责：**门卫 / 安保**——最怕别人受伤，负责在门口挡风遮雨（落差：往日巡山神兽 → 现在举着小伞等大家回家）。
- **疗愈前症状**：怕生，见生人就炸毛低吼（其实是吓唬自己）；想靠近又不敢，只敢在门后露一只耳朵。
- **疗愈后蜕变**：变成可靠门卫，会叼着小伞给晚归的异兽挡雨；翅膀扑腾不起来，但努力扑腾表达开心。
- **视觉关键词**：奶白底橘斑、豆腐块飞翼、圆虎爪、委屈眉。

### 2. 九尾狐 · 青丘傲娇大使
- **本相 & 出处**：《山海经·南山经》"青丘之山……有兽焉，其状如狐而九尾"——青丘的九尾灵狐，尾巴蓬若云霞。
- **落魄由来**：灵气稀薄，九条尾巴失了滋养，蓬不起来，一条条蔫着。
- **可爱化设定**：圆滚滚的橙白小狐狸，九条蓬松尾巴像蒲公英团。性格：**傲娇、爱美、嘴硬心软**。职责：**迎宾 / 形象大使**——用魅力安抚新来的害羞异兽（落差：往日青丘最体面的灵狐 → 现在专门哄别人不紧张）。
- **疗愈前症状**：极度爱美又自卑，天天对着水坑照"尾巴够不够蓬"；被夸会炸毛、被说蔫会缩成球；九条尾巴常"各想各的"导致 multitasking 混乱。
- **疗愈后蜕变**：学会接纳自己，九尾整齐摇摆当迎宾扇，自信而温柔，主动带新兽熟悉环境。
- **视觉关键词**：橙白渐变绒毛、九条蒲公英尾、桃心鼻头、尖圆耳。

### 3. 饕餮 · 不浪费的主厨
- **本相 & 出处**：青铜器饕餮纹"有首无身"——上古司掌百味与丰收的宴食之兽。
- **落魄由来**：灵气稀薄后总担心"下一顿"，见啥都想囤进嘴，连花盆都啃。
- **可爱化设定**：圆胖小熊猫脸大胃王，嘴边永远沾饭粒。性格：**贪吃但慷慨、味觉天才、见不得浪费**。职责：**厨房 / 食材管理**——精打细算绝不浪费，是首席大厨（落差：往日宴食之神 → 现在把"吃"变成照顾别人）。
- **疗愈前症状**：初来"看见啥想吃啥"，连花盆都啃，其实是缺安全感用吃填补；给多了反而焦虑"会不会不够分"。
- **疗愈后蜕变**：蜕变为主厨，用"尝一口就知道缺什么调料"的天赋做治愈料理，把贪吃转化为对他人的照顾。
- **视觉关键词**：米白胖脸、大圆腮、饭粒痣、小围裙、贪吃眉。

### 4. 帝江 · 无脸团宠
- **本相 & 出处**：《山海经·西山经》"有神焉，其状如黄囊，赤如丹火，六足四翼，浑敦无面目"——中央之帝，一团暖黄的元气团。
- **落魄由来**：灵气稀薄，圆滚滚的元气团瘪了一点，存在感更薄，在花园里滚来滚去、想被人看见。
- **可爱化设定**：一颗黄澄澄的毛球团子，没脸但用肢体"说话"。性格：**迷糊、乐天、方向感为零**。职责：**百草园助手 / 开心果**——滚来滚去帮花草松土，用全身卖萌逗大家笑（落差：往日中央之帝 → 现在花园里最勤快的小滚球）。
- **疗愈前症状**：因没脸极度渴望"被看见"，会乱撞墙找存在感；分不清左右，经常滚错房间；越孤单越把自己滚成团的球。
- **疗愈后蜕变**：学会用身体摆出形状"写"情绪信，大家也学会读它的肢体语言，成为全员团宠，还包揽了百草园的松土浇水。
- **视觉关键词**：暖黄绒球、六短腿四小翼、无脸、会鼓腮。

### 5. 毕方 · 怕火的啄木匠
- **本相 & 出处**：《山海经·西山经》"有鸟焉，其状如鹤，一足，赤文青质而白喙"——独足火羽灵鸟。
- **落魄由来**：灵气稀薄，翅膀尖的火苗"噗"地熄了，点不着也急得团团转。
- **可爱化设定**：独脚小火烈鸟雏鸟，暖橙羽带白斑，头顶一撮呆毛。性格：**毛手毛脚、热心过头、怕自己闯祸**。职责：**木工 / 修理匠**——用喙"笃笃"修家具（落差：往日火羽灵鸟 → 现在最怕火星，认真修补）。
- **疗愈前症状**：一紧张就"噗"地冒小火花（灵气漏气，无害但吓自己）；独脚站不稳老摔；越怕越冒火形成恶性循环。
- **疗愈后蜕变**：学会深呼吸压住火花，独脚站得稳；成为可靠修理匠，还会用小火苗烤红薯分给大家。
- **视觉关键词**：暖橙羽、白喙、单细腿、呆毛、小火苗尾。

### 6. 白泽 · 讲故事的学问匠
- **本相 & 出处**：通晓万物之兽，能言人语，知天下之事，黄帝案头神兽，象征智慧。
- **落魄由来**：灵气稀薄，记性变差，怕忘了就拼命背，越背越絮叨。
- **可爱化设定**：雪白小羊驼 / 独角小兽，头顶一支短角，戴副圆框"学问镜"。性格：**话痨、博爱、爱整理**。职责：**图鉴 / 解说员**——把古老传说讲成睡前故事（落差：往日知天下事 → 现在专治"听故事听怕了"）。
- **疗愈前症状**：话太多停不下来，一紧张就背百科，越想安慰越把别人讲困；其实怕自己"记得不够多、帮不上忙"。
- **疗愈后蜕变**：学会把知识讲成温柔小故事，成为收容所"故事姐姐 / 哥哥"，新兽的安眠故事都由它讲。
- **视觉关键词**：云白绒、单短角、圆框镜、小书卷尾、温柔眼。

### 7. 梼杌 · 倔强游乐教练
- **本相 & 出处**：古籍所载的"顽"兽——倔头倔脑的演武灵兽，最守晨操时辰。
- **落魄由来**：灵气稀薄，倔劲使不出来，练功总差一口气，被说"不行"就更别扭。
- **可爱化设定**：圆头圆脑小狮崽，毛炸炸像蒲公英炸开。性格：**熊孩子、倔强、其实想被夸**。职责：**体能 / 游乐教练**——倔劲儿用来陪练不偷懒（落差：往日演武灵兽 → 现在最守时地带大家做操）。
- **疗愈前症状**：不服管，让他向东偏向西，"假装听不见"；其实是怕做不好被嫌弃，用叛逆遮害羞。
- **疗愈后蜕变**：变成最守时的游乐教练，倔劲化作"陪你练到会为止"的耐心，还发明了收容所早操。
- **视觉关键词**：焦糖棕炸毛、方头大眼、小尖牙、不服气嘴。

### 8. 烛龙 · 爱睡的暖炉
- **本相 & 出处**：《山海经·大荒北经》"视为昼，瞑为夜"——钟山之神，掌昼夜之光。
- **落魄由来**：灵气稀薄，光忽明忽暗，白天也亮不起来，作息全乱了套。
- **可爱化设定**：一长条蜷起来的暖光小蛇龙，通体暖黄会发光。性格：**瞌睡虫、恒温小太阳、慢半拍**。职责：**照明 / 暖房**——睡觉时身体发暖光给别的孩子当暖炉（落差：往日掌昼夜之光 → 现在最爱睡觉，但睡得很有用）。
- **疗愈前症状**：严重昼夜颠倒，白天狂睡打呼（呼出小雪花），晚上精神瞪眼发光吓到自己；总觉得自己"太大太亮"不好意思。
- **疗愈后蜕变**：调整作息，学会"按需发光"，夜里当小夜灯；呼出的雪花变成降温凉气，夏天给大家解暑。
- **视觉关键词**：暖黄发光鳞、长条卷、重睫毛、小雪花呼。

### 9. 貔貅 · 透明肚皮管家
- **本相 & 出处**：龙子之一，司库招财之兽，后世奉为招财瑞兽。
- **落魄由来**：灵气稀薄，肚里的小金币越来越少，囤得慌，看见啥都想往肚里塞。
- **可爱化设定**：圆滚滚小狮子存钱罐，肚皮透明能看到里面小金币。性格：**小财迷、护食但大方、爱囤**。职责：**仓库 / 理财**——把资源分配得明明白白（落差：往日司库神兽 → 现在最会规划，关键时刻大方出借）。
- **疗愈前症状**：啥都往肚里塞藏起来，连别人的玩具也"借"来囤；被说小气就鼓成球；其实是怕"不够分"。
- **疗愈后蜕变**：变成精明仓库管家，透明肚皮成了"公共存钱罐"；学会"分享让大家都富"，节日发小红包。
- **视觉关键词**：金白圆肚、透明腹、小卷尾、铜钱纹、得意脸。

### 10. 麒麟 · 暖场小长老
- **本相 & 出处**：仁兽也，"麏身牛尾，狼题肉角"，行步生莲、不履生虫，古人视为太平祥瑞之兆，所至之处必有福。
- **初来状态（祥瑞的落魄小烦恼）**：灵气稀薄，大家却更指望它"您来了一切就都好了"——它把自己端得笔直，不敢打滚、不敢哭、不敢说累；角歪了都要偷偷扶正，怕辜负期待。越完美越孤单。
- **可爱化设定**：圆滚滚的梅花斑小鹿犊，头顶一支软软的小角，脖颈一圈蓬松鬃毛。性格：**温和、懂事、对自己太严**。职责：**和平安抚 / 迎福长老**——用柔和的气场让吵架的小兽静下来。
- **疗愈后蜕变**：学会放下"必须完美"，在收容所当起"暖场小长老"——会陪梼杌发呆、给帝江顺毛，偶尔也四脚朝天打滚。它发现，不端着的时候，大家才敢靠近。
- **视觉关键词**：奶白梅花斑绒、单支软角、蓬松鬃、圆蹄、走路带小莲印。

### 11. 凤凰 · 换羽小歌者
- **本相 & 出处**：百鸟之王，"丹穴之山，有鸟焉其状如鸡，五采而文"，凤凰来仪则天下安宁。
- **初来状态（祥瑞的落魄小烦恼）**：灵气稀薄，正赶上换羽期——旧毛掉了一半、新毛没长齐，灰扑扑秃秃的；它躲在花盆后不敢见人，怕被说"这也叫凤凰？"，连歌都不敢唱，怕一开口掉更多毛。
- **可爱化设定**：圆胖的小雏凤，头顶一撮小火苗羽冠，一身粉彩渐变翎毛。性格：**爱唱、敏感、有点小要强**。职责：**节庆歌者 / 疗愈吟唱**——用软软的嗓音给大家唱安眠曲。
- **疗愈后蜕变**：换羽期也被好好爱着——大家轮流给它顺毛，它重新敢开口唱，发现"不完美也能很好听"。如今当节庆歌者，换羽季还开"掉毛派对"和小朋友一起捡羽毛做书签。
- **视觉关键词**：粉彩渐变翎、小火苗羽冠、圆胖身、换羽小绒毛球、尾翎拖地。

### 12. 鲲鹏 · 云海小向导
- **本相 & 出处**：《庄子·逍遥游》"北冥有鱼，其名为鲲……化而为鸟，其名为鹏"——游于海、翔于天的逍遥神兽。
- **初来状态（祥瑞的落魄小烦恼）**：灵气稀薄，鼓不起气变鹏，卡在半鲲半鹏——水里待着想飞、天上待着想游，两头都像家又都不像家；它一会儿变鱼一会儿变鸟，把自己绕晕，怕被问"你到底是什么"。
- **可爱化设定**：圆乎乎的小鲸鱼（鲲形态）能"噗"地鼓成圆滚滚小鸟（鹏形态），两态切换像吹气球。性格：**好奇、慢热、有点迷糊**。职责：**云海向导 / 运输**——驮着小兽和包裹在云里穿行。
- **疗愈后蜕变**：明白两种形态都是自己——鲲时安静游、鹏时快乐飞，哪态都自在。如今当云海向导，载着大家去看云上的日落，偶尔兜风兜到迷路，但迷路也挺开心。
- **视觉关键词**：圆鲸胖身、小短鳍、云朵纹、可鼓成圆鸟、带小翼。
