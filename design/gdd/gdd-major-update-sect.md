### 0.3 三个根因（本方案要解决的）
1. **合成复杂度不足**：6 阶封顶、无跨族配方、无特殊格，第 2~3 天玩家就"合成到头"。
2. **玩法闭环不强**：交付委托只换数值（暖玉/经验），没有"看得见的宗门变化"；岗位产出不反哺棋盘；目标链只有 3 步短链。
3. **叙事不成体系**：山海经 IP 只贴在角色设定上，没有变成"背景、目标、章节、悬念"四件套；缺少肥鹅式"每完成一单就离剧情推进更近"的拉力。

## 1. 总纲：山海宗门叙事主线（用户核心想法落地）

### 1.1 一句话定位更新
> **末法时代，灵气稀薄。**昔日各守天职的神兽们失了滋养，一只只落魄下来——神骏的天狐尾巴耷拉着，能点灯照夜的烛龙白天也打不起精神。你继承了一座荒废的宗门，**用合成凝聚天材地宝、用温柔照料补足灵气**，帮它们重焕精神、各归其位，把宗门重新建成山海界的温暖家园。

肥鹅健身房的"扩建健身房" = 本作的"**重建宗门**"；肥鹅的"章节任务" = 本作的"**卷章**"（每一卷 = 一只神兽的完整疗愈弧线 + 一片宗门区域的修缮）。

### 1.2 世界观三层（把《山海经》变成游戏背景，且全程无恐怖）
- **上古**：山海界灵气充沛，神兽各守天职——狐守青丘、虎踞山门、龙烛照夜；一座宗门以温柔之道照料万物，人兽两界安宁。
- **变故**：**末法时代来临，灵气日渐稀薄**。神兽失去滋养，纷纷"落魄"：尾巴不蓬了、火苗点不着了、夜里发不出光了、本领失灵心气也散了……宗门守不住灵气，渐渐荒废，只剩山门残垣与满园杂草。
- **如今**：玩家继承掌门之位，重开山门。**疗愈 = 温养灵气；蜕变 = 重焕精神；上岗 = 神兽自愿留下任职。**

> **可爱红线（用户锁定）**：神兽**自始至终可爱（或威严）**。所谓"落魄"只是软萌的状态修饰——毛塌一点、瘦一点、眼神蔫一点、缩成一团，**绝无凶恶/恐怖形态**；蜕变是从"落魄软萌"到"精神焕发"，不是"从可怕变可爱"。
> **与既有设定对接**：创伤档案 → **「落魄档案」**；"初来症状" → 落魄表现（beast-cast 各兽的疗愈前症状本就是软萌的，仅把叙事外衣从"传说凶化"换成"灵气不足"）；图鉴 → 《山海册》"本相 + 宗门实录"。**落差萌**的新表述：昔日呼风唤雨的神兽，今天软乎乎地等你照顾。

## 3. 委托体系扩容（解决"内容量差两个数量级"）

### 3.1 槽位与池
- 槽位 3 → **5**：主线（卷章）/ 修缮 / 医案 / 访客（日常）/ 活动；
- 模板 4 → **启动 40+**，每卷 12–18 个（修缮 3 段×4–6 + 医案 3–5 + 访客 3–5）；
- 类型扩 5 种：交付物品 / 交付多件 / 交付组合（跨族配方产物）/ 用指定物品照料神兽 / 展示蜕变兽。

### 3.2 奖励与难度曲线
- 奖励四件套：**暖玉 + 建材 + 声望 + 疗愈品**；主线委托额外给"卷章进度"，修缮委托额外给"区域修缮度"；
- 需求阶位随卷爬升：卷一 1–3 阶 → 卷六 4–6 阶 → 卷十二 8–10 阶 + 跨族配方（防"永远合成低阶"）。

### 3.3 刷新
访客 3 小时一轮 / 每日免费刷新 1 次（九尾狐岗位 `freeRefresh` 沿用）；修缮/医案随卷章固定，不过期不惩罚（零失败）。

## 4. 宗门修缮（元目标 · 肥鹅的"健身房肉眼变好"）

- 每区域 3 段（荒废 → 修补 → 焕新），每段 = 4–8 个修缮委托；完成一段 → **场景部件即时替换**（瓦当补上、灯亮起、藤蔓撤下）+ 解锁该段功能（生成器升级、新槽、新访客）。
- 顶部常驻「宗门修缮度」进度条（当前区域 % 与全宗 %）。
- 区域焕新完成 = 该卷幕四蜕变的**情绪铺垫**：区域变美的瞬间即焕新演出前奏。
- 复用现有 `courtyard-scene` 分层结构与 `buildings` 3 级美术管线，按"区域×3 段"扩图（见 §10 产能风险）。

## 6. 成长线统一（修复"两套系统并存"）

现状问题：merge_slice 用 5 阶成长（affection/heal/exp），旧 GDD 用 Trust/Heal 双轨 + 蜕变，两套并存、口径不一。统一方案（待拍板，见 §9 决策点 2）：

- **5 阶 = 疗愈轨迹**：每阶一个"焕新阶段"（已有 5 阶美术资产全部复用）；
- Trust/Heal 双轨作为**阶内进度条**（沿用 GDD §0 公式与对症矩阵）；
- 关键演出：**阶 2→3 = 小焕新**（毛色变亮、精神变好），**阶 4→5 = 完全焕新 + 上岗**（卷终大演出）；
- 成长三来源：合成交付 → exp（已有 `growthOrderRewards`）；照料/医案 → affection/heal；小游戏 → ScoreMult；
- GDD §0 的 `Trust≥60 / Heal≥100` 阈值映射为"阶 2→3 门槛"（数值待校准）。
