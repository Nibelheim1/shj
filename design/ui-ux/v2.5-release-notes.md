## 📊 数据层改动

### 四阶段阈值（`GAME_DATA.balance`）

| 阶段 | 条件 | 视觉 |
|------|------|------|
| s0 症状态 | 默认 | 发抖、低饱和、不跳跃 |
| s1 松动期 | trust ≥ 20 **或** heal ≥ 25 | 正常呼吸、偶尔张望 |
| s2 软化期 | trust ≥ 40 **且** heal ≥ 60 | 呼吸饱满、频繁张望、偶尔跳 |
| s3 蜕变期 | isCured | 呼吸+摇摆+跳跃最活跃 |

### API

```js
// 计算阶段（0/1/2/3）
const stage = GAME_DATA.calcBeastStage(beast.trust, beast.heal, isCured);

// 取对应立绘
beastDef.art['s' + stage];  // → 'art/characters/穷奇_s0.png' 等

GAME_DATA.stageLabels;  // ['症状态', '松动期', '软化期', '蜕变期']
```

## 🎬 蜕变剧场（5 段式）

| 阶段 | 时长 | 效果 |
|------|------|------|
| 前奏 | 2s | 柔光聚集 + 角色脉动发光 |
| 包裹 | 2s | 光茧形成 + 粒子向中心汇聚 |
| 转化 | 2.5s | 光茧心跳 + 粒子环绕旋转 |
| 绽放 | 1.5s | 花瓣爆发 + 新形象从模糊到清晰 |
| 亮相 | 2s | 角色弹跳入场 + 名字 + 称号 |

总时长约 10 秒，`playTransform(def_id, onDone)` 支持完成回调。
