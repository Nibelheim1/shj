# 场景 / 角色 / UI 视觉体验修改建议（V1 → V2.5 升级方案）

**项目**：小动物山海经 · 神兽疗愈收容所
**类型**：玩家体验评审 → 改进建议文档
**对应现状**：原型 V2（渲染器 V2 + UI V2 + 五大小游戏 V2）
**目标**：从"贴画拼贴感"升级到"活的绘本庭院"，让玩家第一眼就想留下来摸摸它。
> ⚠️ 历史评审快照：文中"相柳"等角色/场景条目已被 2026-08 大更新废止（12 兽阵容），见 `design/gdd/gdd-major-update-sect.md` 附录 C。本文仅作存档，不再作为现行设计依据。

---

## 全局设计原则（先对齐，再动手）

### 原则一：画面是"演"出来的，不是"摆"出来的
现在的问题：所有元素（角色/建筑/装饰/粒子）都是独立渲染的，各动各的，没有"导演"。
改进方向：加入"场景编排层"，让角色之间、角色与环境之间、时间与事件之间有联动。
- 角色的动作 = f(时间, 状态, 周围有谁, 玩家在不在)
- 环境的变化 = f(时段, 天气, 节日, 收容所等级)
- 玩家的操作 = 触发一段"表演"，而不是改一个数字

### 原则二：渐进式视觉反馈，不是"满了就变"
现在的问题：Trust/Heal 从 0 到 99，角色完全不变；到 100 突然叮一下。
改进方向：把"蜕变"拆成 3–4 个视觉阶段，让玩家亲眼看到"它在变好"。
- 每跨过一个阈值，外观/动作/表情就变化一点
- 最终的"蜕变动画"是高潮，不是唯一一次变化

### 原则三：主场景是游戏本体，面板是辅助
现在的问题：玩家 70% 时间在点 DOM 面板看文字，30% 时间看场景。
改进方向：反过来——70% 时间玩家在场景里和角色互动，30% 时间打开面板看信息。
- 能在场景里做的事，不在面板里做
- 信息尽量用视觉方式表达（气泡、表情、动作），不用文字列表

### 原则四：温柔的引导，不是沉默的空白
现在的问题：零失败 ≠ 零引导。新手进去不知道做什么。
改进方向：用"软引导"替代新手教程——角色的需求气泡、环境中的暗示、温柔的提示。

# 第一部分：场景（Scene）

## 1.1 现状诊断

| 问题 | 玩家感受 | 严重度 |
|------|---------|--------|
| 场景是静态底图 + 贴图层，没有空间层次 | "像一张贴了贴纸的画" | 🔴 高 |
| 角色和场景透视/光影不统一，像悬浮 | "角色是飘着的" | 🔴 高 |
| 建筑/装饰是贴图，点了只弹面板 | "点了没反应，没什么可玩的" | 🟡 中 |
| 粒子效果（花瓣/萤火虫）与场景氛围脱节 | "花瓣一直在飘，不知道为啥" | 🟡 中 |
| 日夜循环 3 分钟一轮，节奏太快 | "怎么天又黑了，烦" | 🔴 高 |
| 场景没有可探索/可互动的小细节 | "看了两分钟就腻了" | 🟡 中 |
| 装饰摆在预设坑位，不能自由摆放 | "布置了个寂寞" | 🟢 低 |

## 1.2 场景分层重构建议

### 方案：从"一张图"改为"六个可交互层"

```
┌─────────────────────────────────────┐
│  ⑥ 天空层（云/月/星，日夜循环）        │
│  ⑤ 远景层（山/浮岛，视差慢动）         │
│  ④ 中景层（建筑/大树，可点击互动）     │
│  ③ 庭院地面层（草地/小路，脚印/花）    │
│  ② 角色/道具层（异兽/玩具，走动互动）  │
│  ① 前景层（草丛/花瓣，遮挡增强纵深）   │
└─────────────────────────────────────┘
```

**具体改动：**

### 层⑥ 天空层
- 去掉固定的天空图，改为程序化渐变天空
- 云：2–3 朵缓慢飘动的云，白天显现、夜晚变淡
- 夜晚：星星（位置随机，微闪烁）+ 月亮（随日夜周期变化位置）
- **日夜节奏调整**：从 3 分钟一周期 → **20 分钟一周期**（约等于一次完整游戏会话），且玩家可手动切换
- 特殊天气：下雨（雨滴粒子 + 角色躲屋檐下）、下雪（雪花 + 角色裹成球）——与照料/剧情联动

### 层⑤ 远景层
- 远山/浮岛：缓慢左右视差移动（跟随摄像机微移）
- 加入远景小细节：远处飞的小鸟、山顶的微光——"世界很大，我这只是一角"

### 层④ 中景层（建筑）
- **建筑要有"呼吸感"**：
  - 兽舍门口偶尔探出头（有兽在里面时）
  - 药房烟囱冒小烟（正在配药时）
  - 药圃里草药随风轻轻摇晃（有种了草药时）
  - 厨房飘食物香气粒子（饕餮在岗时）
- **建筑点击不只是弹面板**：先有一个建筑的动画反馈（门开了、灯亮了），再进入面板
- 建筑有"近大远小"的透视关系，而不是平铺在画面上

### 层③ 庭院地面层
- 地面不是一张完整的图，而是"草地 + 小路 + 小花"的组合
- 玩家走过的地方（点击过的位置）会留下淡淡的脚印，几秒后消失
- 地上有随机的小细节：四叶草、小蘑菇、掉落的羽毛——可点击，点了有小惊喜（比如飘起一个爱心 + 一句碎碎念）
- 地面有高度差：台阶、土坡、水池——角色在不同高度上站着，增强空间感

### 层② 角色/道具层（详见第二部分"角色"）
- 角色不是站在固定 3 个点上，而是可以在庭院里自由走动（巡逻路径）
- 角色之间会碰面、互动

### 层① 前景层
- 画面底部加一层草丛/花朵，随角色走动轻微晃动
- 偶尔有花瓣/落叶从前景飘过（比中景的粒子大、速度快，增强纵深感）

## 1.3 场景互动增强

### "点哪都有反馈"原则
- **点草地**：草晃一下 + 飞出 1–2 只小蝴蝶/萤火虫
- **点花朵**：花朵摇晃 + 掉一片花瓣
- **点水池**：水波纹扩散
- **点建筑**：建筑动画 + 进入（见上）
- **点空白处**：什么都不发生，但角色可能会朝你点的方向看一眼

### 场景事件（随机小剧场）
每隔一段时间（5–10 分钟）触发一个场景小事件：
- 穷奇偷偷从门后探出脑袋，看见玩家在看又缩回去
- 相柳的一个头在打瞌睡，被另一个头戳醒
- 九尾狐对着水池照尾巴，越照越开心
- 帝江滚着滚着滚歪了，自己又滚回来

> 这些小剧场**不需要玩家操作**，就是让玩家觉得"它们在自己生活"。
> 玩家的快乐很多时候来自"我看到了一个别人可能没看到的小细节"。

# 第二部分：角色（Character）

## 2.1 现状诊断

| 问题 | 玩家感受 | 严重度 |
|------|---------|--------|
| 只有"疗愈前"和"疗愈后"两帧，中间没有渐进变化 | "条在涨，但它看起来没变" | 🔴 高 |
| 待机动作太简陋（呼吸+摇摆+偶尔跳） | "像个会晃的贴纸" | 🔴 高 |
| 没有情绪状态的视觉表达 | "不知道它现在开心还是难过" | 🔴 高 |
| 照料反馈是程序化小特效，和角色脱节 | "点了按钮冒点泡泡，没在撸它的感觉" | 🔴 高 |
| 角色之间没有互动 | "各站各的，像展品" | 🟡 中 |
| 蜕变动画就是一堆粒子，没有仪式感 | "就这？我等了半天" | 🔴 高 |
| 角色语音/叫声完全没有 | "没灵魂" | 🟡 中 |

## 2.2 角色三阶段渐进外观

### 方案：把"一次蜕变"拆成"四个阶段"，每个阶段都有视觉变化

```
阶段 0：症状态（初始）
  ↓ Trust 30
阶段 1：松动期（开始信任你）
  ↓ Trust 60 + Heal 50
阶段 2：软化期（明显变好）
  ↓ Heal 100
阶段 3：蜕变期（完全形态 · 仪式动画）
```

**各阶段视觉变化示例（以穷奇为例）：**

| 阶段 | 外观 | 动作 | 表情 |
|------|------|------|------|
| 0 症状态 | 毛炸着、耳朵背后面、身体缩成一团、翅膀夹紧 | 发抖、不敢看人、原地踱步 | 委屈眉、眼睛往下看 |
| 1 松动期 | 毛不那么炸了、一只耳朵悄悄竖起来、翅膀松了一点 | 偶尔看你一眼又移开、尾巴轻轻晃 | 眼神柔和一点了 |
| 2 软化期 | 毛顺了、两只耳朵都竖起来、翅膀偶尔扑腾一下 | 会主动靠近你一点、打哈欠 | 眼神亮晶晶、嘴角微微上扬 |
| 3 蜕变期 | 毛蓬松发亮、翅膀展开但不飞、尾巴翘起来 | 蹦蹦跳跳、扑过来蹭你 | 开心笑眼、耳朵朝前 |

**为什么要拆成 4 阶段？**
- 玩家每做几次照料就能看到变化 → "我的努力有用"的正反馈更强
- 最终蜕变是"量变到质变"的高潮，而不是唯一的一次变化
- 信任值和疗愈进度从"抽象数字"变成"看得见的改变"

## 2.3 角色待机动作系统

### 方案：每只兽 5–8 个闲置动作，按状态/心情切换

**通用动作库（所有兽都要有变体）：**
1. **呼吸**（基础，永远在）—— 但不是匀速缩放，而是吸气快、呼气慢，更自然
2. **眨眼**—— 随机间隔 3–8 秒眨一次，偶尔连眨两下
3. **张望**—— 头慢慢转向左边，停 2 秒，再转向右边
4. **打哈欠**—— 稀有，30–60 秒触发一次，嘴巴张到最大再慢慢闭上
5. **挠痒**—— 用爪子/翅膀挠一下身体
6. **整理毛发**—— 低头舔/梳一下自己的毛
7. **伸懒腰**—— 身体拉长 + 弓背，然后放松
8. **打瞌睡**—— 头一点一点的，最后撑不住眯几秒

**状态专属动作（根据症状/心情变化）：**
- 焦虑时：踱步、来回走、抖身子
- 开心时：蹦一下、转圈、摇尾巴
- 害羞时：缩脖子、捂脸/躲尾巴后面
- 困倦时：头下垂、眼睛半眯

**触发逻辑：**
```
当前动作 = f(状态, 时间, 随机, 周围有谁)
```
- 状态权重：症状态 → 焦虑类动作多；软化期 → 放松类动作多；蜕变后 → 开心类动作多
- 周围有其他兽时，有概率触发互动动作（碰鼻子、一起玩、互相舔毛）

## 2.4 照料互动重做

### 原则：玩家的手 = 玩家的化身

现在的照料是"点按钮 → 触发小游戏 → 加数值"，玩家和角色之间没有肢体接触感。
改进方向：**把照料做成"在角色身上直接操作"**。

### 喂食（从消消乐小游戏 → 手喂互动）
- 食物出现在玩家"手"里（光标/手指），你把食物拖到角色嘴边
- 角色先闻一闻（犹豫），然后小心地吃一口
- 对症 = 大口吃 + 摇尾巴；不对症 = 吃了但表情一般
- 吃完后舔舔嘴，看你一眼

### 清洁（从污渍点击 → 擦拭互动）
- 角色身上有污渍/泪痕（位置和形状对应症状）
- 你用毛巾/海绵在它身上擦（滑动操作）
- 每擦一下，污渍淡一点，角色表情放松一点
- 擦完后角色抖抖身子，毛蓬起来

### 梳毛（从路径滑动 → 直接梳毛）
- 角色的毛乱糟糟的（症状态尤其明显）
- 你用梳子顺着毛的方向梳（按住滑动）
- 梳过的地方毛变顺、变蓬
- 梳到舒服的地方，角色会眯眼睛、发出呼噜声
- 梳错方向（逆着毛），角色会抖一下但不生气（零失败）

### 陪玩（从节奏游戏 → 抛接/追逐互动）
- 你扔一个玩具出去，角色跑过去捡回来
- 或者：你用逗猫棒/光点在地上晃，角色追着跑
- 玩嗨了会在地上打滚、翻肚皮
- 玩累了会趴在地上喘气，舌头伸出来

> **为什么放弃"专业小游戏"的方向？**
> 消消乐、节奏游戏这些，一旦做成独立小游戏，玩家的注意力就从"和角色互动"转移到"玩好这个游戏"上了。
> 治愈游戏的核心不是"游戏好玩"，而是"和它在一起的感觉好"。
> 小游戏越复杂、越有挑战性，就越偏离"温柔陪伴"的主题。

## 2.5 蜕变仪式重做

### 方案：30 秒的蜕变剧场，不是 2 秒的粒子特效

**蜕变分镜（以九尾狐为例）：**

1. **前奏（5s）**：角色全身发出柔和的光，毛开始轻轻飘动，周围的花瓣/光点向它聚集
2. **包裹（5s）**：光越来越亮，把角色整个人包裹成一个光茧，心跳声"咚——咚——"
3. **转化（10s）**：光茧内部形态变化（可以看到剪影在变化），毛在舒展、尾巴在变蓬
4. **绽放（5s）**：光茧"啪"地炸开，变成满屏花瓣/光点，新的形态从光里走出来
5. **亮相（5s）**：新角色站在画面中央，转一圈 / 摆个 pose，看着你，说一句专属台词
6. **收尾（玩家点击后）**：画面柔焦，弹出"它变软了，变得更像自己了" + 图鉴更新提示

**音效配合：**
- 前奏：轻柔的音乐渐强
- 包裹：心跳声 + 嗡嗡的共鸣
- 绽放："叮——"的清脆声 + 花瓣飘散的音效
- 亮相：温暖的音乐主题

**零失败依然成立**：蜕变一定会成功，只是触发的早晚问题。

## 2.6 角色互动（羁绊的视觉化）

现在羁绊是"升级解锁一段文字"，玩家感受不到。
改进方向：**让羁绊在场景里"演"出来。**

### 互动等级与触发
| 羁绊等级 | 场景互动 |
|---------|---------|
| Lv1 初见 | 碰到了会互相看一眼，然后各自走开 |
| Lv2 相识 | 偶尔凑到一起嗅一嗅，然后一起待一会儿 |
| Lv3 信赖 | 经常待在一起，互相舔毛/梳毛 |
| Lv4 依偎 | 睡觉的时候挨在一起，玩的时候追着跑 |
| Lv5 家人 | 触发"合体小剧场"（专属动画 + 台词） |

### 11 组羁绊 → 11 个专属小剧场
比如：
- **穷奇 × 九尾狐**：九尾狐在梳理尾巴，穷奇在旁边假装不看，但尾巴出卖了它（尾巴在摇）。九尾狐发现了，把一只尾巴盖在穷奇头上。穷奇炸毛但没躲开。
- **相柳 × 饕餮**：饕餮在吃东西，相柳九个头都看着它流口水。饕餮叹了口气，把食物分成九份，一个头一份。
- **白泽 × 帝江**：白泽在讲故事，帝江用身体摆形状"插话"。白泽点点头说"对对对就是这样"。

> 这些小剧场**是随机触发的**，玩家要"碰运气"才能看到。
> 看到的玩家会有"哇我居然看到了"的惊喜感，会截图分享。
> 没看到的玩家会想"下次再等等看"，增加留存。

# 第三部分：UI 界面

## 3.1 现状诊断

| 问题 | 玩家感受 | 严重度 |
|------|---------|--------|
| 面板全是文字列表，没有画面感 | "像个管理后台，不像游戏" | 🔴 高 |
| 底部动作栏太像工具栏，没有绘本感 | "功能按钮一堆，不知道点啥" | 🟡 中 |
| HUD 信息太多太满 | "像在玩数值游戏" | 🟡 中 |
| 已有的手绘 UI 素材（标题横幅/角花/弹窗底）没用上 | "CSS 画的不够有温度" | 🟡 中 |
| 面板之间跳转关系混乱 | "点了不知道去哪、怎么回来" | 🟡 中 |
| 图鉴/羁绊没有大图，只有文字 | "收集了个寂寞" | 🔴 高 |
| 没有新手引导 | "进去一脸懵" | 🔴 高 |
| 所有信息都用文字说，没有视觉化 | "看字好累" | 🟡 中 |

## 3.2 信息架构重做

### 原则：能在场景里表达的，不做面板；能用图表达的，不用字

### HUD 精简（从 5 个 chip → 2 个核心 + 折叠）

**常驻显示（左上角）：**
- 🏡 **收容所 Lv.X**（等级是核心身份感）

**常驻显示（右上角）：**
- 💎 **暖玉数量**（货币是核心资源）

**点击"..."按钮展开：**
- 食材数量 + 图标
- 声望等级 + 图标
- 当前天数
- 设置按钮

> 为什么把食材/声望/天数收起来？
> 因为这些不是"每时每刻都需要看"的信息。
> 玩家大部分时间只需要知道"我有多少钱、我几级了"。
> 信息越少，画面越干净，越有治愈感。

### 底部动作栏重做（从 2 行 6 按钮 → 1 行 4 按钮 + 浮动）

**底部常驻 4 个核心按钮：**
1. **🐾 异兽**（原来的收容 + 图鉴 + 羁绊合并）—— 这是游戏核心
2. **🏠 家园**（建造 + 装饰 + 升级合并）—— 经营核心
3. **📋 委托**（事件 + 访客 + 配药合并）—— 内容入口
4. **⚙️ 更多**（设置 / 存档 / 关于）

**浮动按钮（场景中）：**
- 🎁 每日签到 / 活动提醒（有新内容时才出现，闪一下吸引注意）
- ❓ 帮助 / 我该做什么（新手期出现，老手可隐藏）

> 为什么大幅减少按钮数量？
> 因为休闲治愈游戏的界面应该"呼吸感"，而不是"操作感"。
> 玩家打开游戏的第一反应不应该是"我该点哪个按钮"，而是"哇好可爱，让我摸摸它"。

## 3.3 核心面板重设计

### 面板通用视觉规范
- 用上已有的手绘 UI 素材：`弹窗背景.png` 作面板底、`ui_panel_corner_tl.png` 作四角装饰、`ui_title_banner.png` 作标题条、`ui_divider_floral.png` 作分割线
- 面板边框：手绘感的不规则边缘（不是完美的圆角矩形）
- 面板进入动画：从下往上滑入 + 轻微弹性，像翻开一张小卡片
- 关闭方式：点面板外区域 / 点右上角小叉 / 向下滑动关闭（手机上更自然）

### 异兽面板（收容 + 图鉴 + 羁绊，三合一）

**结构（三个 Tab）：**
```
┌─ 在家 ─┬─ 图鉴 ─┬─ 羁绊 ─┐
│         │         │         │
```

#### Tab 1：在家（当前收容的异兽）
- 网格布局：每只兽一张小卡片，卡片上是**它当前状态的立绘缩略图**
- 卡片角标：💬 有需求 / ❤️ 可以蜕变 / ⭐ 新解锁
- 点卡片：进入该异兽的详情面板

**异兽详情面板：**
- 顶部：大立绘（当前阶段的样子）+ 名字 + 状态标签
- 中部：两根进度条（信任值、疗愈进度）—— 但不是光秃秃的条，而是用**视觉化方式**表达：
  - 信任值：一颗心，从空心慢慢变满，颜色从灰变粉
  - 疗愈进度：一朵花，从花苞慢慢绽放
- 下部：四个照料按钮（喂食/清洁/梳毛/陪玩）—— 但按钮不是文字，是**图标 + 一句话说明**
- 最底部：创伤档案按钮（点了展开，看它的故事）
- 需求气泡：如果它当前有需求，在立绘旁边飘一个小气泡（🍚 饿了 / 🫧 脏了 / 🥺 想玩）

#### Tab 2：图鉴
- 网格布局：已解锁 = 彩色立绘；未解锁 = 剪影/问号
- 点已解锁的卡片：翻面，看前后对比 + 典故 + 彩蛋故事
- **前后对比做成"滑动翻页"**：手指滑动，左边是疗愈前、右边是疗愈后，滑到哪里看到哪里
- 彩蛋故事：做成"翻开一张小信纸"的感觉，手写字体 + 印章

#### Tab 3：羁绊
- 关系图谱：用线条连接有羁绊关系的两只兽，像星座图一样
- 已解锁的连线：金色 + 爱心；未解锁的：灰色虚线
- 点连线：看羁绊故事 + 当前等级 + 解锁条件
- Lv5 的羁绊：有"合体小剧场"的回放按钮（可以重看动画）

### 家园面板（建造 + 装饰 + 升级）

**两个 Tab：建造 / 装饰**

#### 建造 Tab
- 建筑列表，每个建筑一张卡片：建筑图 + 名称 + 当前等级 + 升级按钮
- 升级后：在场景里能看到建筑外观变化（变大、加装饰、冒烟等）

#### 装饰 Tab
- 装饰物品列表（已拥有/未拥有）
- **支持自由拖拽摆放**（不是预设坑位）
- 摆放模式：进入后场景变暗，装饰图标从底部浮起，拖到场景里放，放好后可以微调位置/旋转
- 保存后：装饰永久留在那里

### 委托面板（事件 + 访客 + 配药）

**三个部分（上下排列，不是 Tab）：**
1. **当前委托**（最大最显眼）—— 正在进行的任务，进度可见
2. **待接委托**（列表）—— 可以选择接不接
3. **访客 / 病人**（小小的一排头像）—— 谁来了、有什么需求

> 配药系统整合在这里：病人来了就是一个"小委托"，你去药房配药、回来给药。
> 不再是一个独立的大系统，而是"收容所日常事务"的一部分。

## 3.4 软引导系统

### 原则：用角色引导，不用文字教程

### 新手前 3 步引导

**第 1 步：进入游戏**
- 画面上只有庭院 + 一只躲在兽舍门口的穷奇（只露出半个身子）
- 穷奇头上飘一个气泡："…（偷偷看你）"
- 屏幕上只有一句温柔的提示："它好像有点怕生，要不要过去看看？"
- 玩家点穷奇 → 进入照料面板

**第 2 步：第一次照料**
- 照料面板里，4 个按钮中"陪玩"按钮在轻轻发光（暗示这是最优解）
- 旁边一行小字："它好像有点怕生，陪它玩玩？"
- 玩家点陪玩 → 完成第一次照料 → Trust 涨了 → 穷奇从门后多探出一点身子

**第 3 步：第一次蜕变后**
- 蜕变动画结束后，九尾狐（已经在岗的）走过来，说："新来的小朋友交给我吧～"
- 解锁"上岗"玩法
- 屏幕上出现一个小箭头指向底部"异兽"按钮："你看，它开始帮忙了～"

### 持续引导（贯穿游戏）
- 新功能解锁时，不是弹一个"恭喜解锁 XXX"的文字框，而是：
  - 对应的按钮开始发光
  - 旁边飘一个角色的小气泡："听说药房建好了？要不要去看看？"
- 玩家不知道做什么时，可以点右上角的"❓"，会告诉你：
  - "穷奇好像饿了哦～"
  - "药圃里的草药可以收了～"
  - "今天有客人来拜访呢～"

## 3.5 字体与排版

- **标题字体**：用手写体/书法体（如"霞鹜文楷"、"站酷快乐体"），有绘本感
- **正文字体**：用圆润的无衬线体（如"思源黑体 Rounded"），好读不费力
- **字号**：正文不小于 14px（手机上），标题不小于 18px
- **行间距**：1.5–1.8 倍，宽松透气
- **颜色**：主文字用暖棕色（不是纯黑），次要文字用浅棕色，强调用珊瑚橘

# 第四部分：优先级与落地路径

## 4.1 优先级排序（P0 必须做 / P1 应该做 / P2 可以做）

### 🔴 P0（核心体验，不做就不像个游戏）
1. **角色三阶段渐进外观** —— 让"疗愈"看得见
2. **角色待机动作扩充** —— 从"会晃的贴纸"变成"活的小家伙"
3. **蜕变仪式重做** —— 这是游戏最高潮，不能敷衍
4. **HUD + 动作栏精简** —— 界面先"透气"再说
5. **软引导新手前 3 步** —— 新人不能一脸懵

### 🟡 P1（大幅提升质感）
6. **照料互动从"小游戏"改为"直接互动"** —— 让玩家真的在"撸"它
7. **图鉴 + 异兽详情面板重设计** —— 收集感的核心展示位
8. **场景六层重构 + 建筑呼吸感** —— 场景从"贴画"变"空间"
9. **手绘 UI 素材全面接入** —— 把 CSS 模拟换成真实手绘
10. **角色互动小剧场（3–5 组先做）** —— 羁绊从文字变画面

### 🟢 P2（锦上添花）
11. 场景随机小事件
12. 装饰自由摆放
13. 日夜节奏调整 + 天气系统
14. 音效/BGM/角色叫声
15. 完整 11 组羁绊小剧场
16. 场景小细节互动（点花点草点水池）

## 4.2 建议的落地顺序（按版本迭代）

### V2.5 版本（1–2 周）：角色活起来
- 角色三阶段渐进外观（先做 3 只主力兽）

## 4.3 投入产出比提醒

**最高 ROI 的三项改动（做了立刻感觉"不一样了"）：**
1. **角色三阶段外观 + 更多待机动作** → 角色从"贴纸"变"活的"，成本主要是美术
2. **蜕变仪式重做** → 游戏最高潮的体验，做好了玩家会截图分享
3. **界面精简 + 软引导** → 降低新玩家流失率，让更多人能撑到第一次蜕变

**最低 ROI 的（可以先不做）：**
- 装饰自由摆放 → 虽然自由度高，但玩家真正去摆的不多
- 天气系统 → 氛围感加分但不是核心
- 11 组羁绊全做 → 先做 3 组试水，看玩家反应再加
