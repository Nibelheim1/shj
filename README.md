# 小动物山海经 · 疗愈所竖切片

这是一个可直接运行的 H5 竖屏游戏竖切片。当前正式入口是合成主线 MVP：**7×8 棋盘、6 阶合成、穷奇 / 九尾狐 / 饕餮三兽，以及 7 日疗愈闭环**（病症委托 → 合成 → 庭院照料 → 每日目标与解锁）。

## 运行

```powershell
python -m http.server 8080
```

打开正式入口：`http://localhost:8080/prototype/merge_slice.html`。

构建后的部署入口是 `dist/index.html`，可直接在 `dist/` 目录启动静态服务器。

`prototype/index.html` 仅保留为旧版照料原型的 **legacy reference**，不代表当前合成入口，也不是本阶段验收入口。

## 当前 MVP 内容

- 7×7 合成棋盘（49 格）：更大格子与物品显示，开局留出更多操作空间
- 1–10 阶物品合成与病症委托交付
- 常驻生成器不限在线次数：在线点击只耗灵力；升级消耗暖玉+灵力并受宗门等级与信物前置限制
- 造物生成器由部件合成：不耗灵力、次数有限，用尽自动消散并返还部件
- 订单难度 8 档递进：后期要求配方成品与造物生成器产物，完成奖励灵力与部件
- 穷奇、九尾狐、饕餮等 **12 只神兽**，每只 5 个形态全量立绘与阶段素材
- 山海册图鉴分两页展示 12 兽，翻页查看全部形态、故事与岗位
- 宗门页（P1）：栖霞宗 / 末法时代世界观、卷一·穷奇篇五幕卷章、3 区域 × 3 段修缮委托与卷终钩子
- 宗门舆图（新）：14 区域完整地图 + 建筑点位、灵雾锁区与解锁条件、交付修缮后的"世界变化卡"、区域段位永久加成、6 位自主散步 NPC、庭院场景随宗门修缮同步变亮
- 长按任意素材可查看完整合成路线与“材料来源”提示，并列出它当前被哪些委托/配方使用；订单难度随宗门阅历提升至 8 阶材料
- 首次进入会依次播放欢迎引导与四页玩法说明；所有主要模块（委托、棋盘、配方、药匣、回收、庭院建筑、宗门舆图、图鉴等）都支持长按查看“干什么 / 需要什么 / 有什么用”
- 顶部“下一步”按最短可完成路径动态提示：可交付委托 > 一步合成 > 庭院收集素材 > 成长 > 宗门修缮；棋盘满时点击生成器会弹出“一键回收最低阶素材”行动面板
- 素材不再区分来源神兽：棋盘与订单都不显示神兽角标，订单只要求族与阶位；梳妆/陪玩族素材来自对应庭院小游戏，需要时点开委托详情可直接跳转并高亮建筑
- 订单卡只展示标签、任务名与素材图片；配方柜物品以图片与其他素材横排（卡片自适应加宽、高度封顶），点开订单详情才显示配方柜说明
- 常驻生成器随时间积攒“离线储备”：灵力耗尽时可动用储备继续产出；生成器详情显示产出效率（以 Lv1 为基准的升级收益）与储备余量
- 配方柜与配方台为全部配方补充了专用图片素材（安神药包、灵木床、疗愈餐等），长按配方可看图、材料来源与用途；灵泡与宝箱模块已从竖切片移除
- 7 日目标闭环：灵力、暖玉、经验、升级、委托和庭院照料相互回流
- 叙事主线《山海·异兽栖霞》：十二盏归灯贯穿 12 兽 12 卷；全局文案与卷一全量已写入 `data.js`，交付委托会播放对应“世界变化”反馈；文案规范见 `design/narrative/`
- 医馆、药圃、梳洗台等庭院热点，以及由建筑进入的梳理 / 陪玩互动

### 庭院照料小游戏（当前实现）

- 庭院不再提供独立的梳理、陪玩按钮：点击梳洗台进入 **7×8 梳理消消乐**，点击亭子进入陪玩连连看；设施升级、岗位产出和可购买背景从庭院快捷弹层打开。
- 梳理消消乐采用滑动交换：4 连生成条状块，L/T 形生成炸弹，5 连生成彩石，支持特殊块组合；道具为灵锤、重排、木梳，消除会积累并消耗局内灵力。
- 陪玩连连看按轻松 / 标准 / 困难 / 大师递进：图标种类为 6 / 8 / 9 / 10 种，棋盘从 5×6 到 8×8，转弯限制、锁链、动态落位和错配时间惩罚逐级增加；无可行对时自动重排，道具次数随难度收紧，清空、超时、跳过均按零失败基础档位结算。
- 庭院默认使用免费的晨光庭院，并提供桃霞山庭、月影竹溪两幅可用暖玉购买的背景；购买后可随时切换，选择会写入 v4 存档。
- HUD 右上角提供背景音乐/音效开关；首次点击页面后解锁循环庭院音乐，合成、交付、照料、升级和购买均有轻量音效，偏好保存在本地。
- 第一次有效照料才推进 `careDone`、信任与疗愈；重复小游戏不能绕过三段故事治疗节点。表现只影响 1–3 阶照料素材奖励。
- 合成、庭院、图鉴三个主页面，以及两种照料小游戏，均以 390×844 为基准严格保持手机一屏；辅助内容使用弹层，不通过页面纵向滚动承载。

## 入口与素材

- 正式入口：`prototype/merge_slice.html`
- 入口样式：`prototype/merge-slice.css`
- 浏览器启动器：`prototype/merge-slice.js`
- 数据配置：`prototype/js/merge/data.js`
- 纯状态核心与 v4 迁移：`prototype/js/merge/core.js`
- UI 绑定：`prototype/js/merge/ui.js`

素材位于 `prototype/assets/art/`，竖切片使用其中的合成素材、12 兽阶段素材、match3 素材与庭院背景。

## 构建与腾讯云静态托管

```bash
npm run build
tcb hosting deploy ./dist
```

构建脚本会安全复制可用的模块脚本和素材；个别异兽缺少 s1 / s2 阶段图时保留已有文件，由运行时阶段回退处理，不会阻断构建。
