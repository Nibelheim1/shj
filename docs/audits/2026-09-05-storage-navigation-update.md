# 行囊入口收敛与四栏导航

移除独立行囊页面与底部按钮，底部保留「灵阵、宗门、庭院、山海册」。四个入口等宽，左右留白对称，图标沿用原素材并按比例显示；切换时仍只改变选中光晕，图标和文字位置不跳动。

药匣改为灵阵内底部抽屉。选中棋盘素材后打开药匣，可点「存入 · 素材名」；点击匣内素材取回棋盘。原来的素材信息栏被旧样式隐藏，因此将存入操作直接接进抽屉。扩容后原地显示新格，取出后回到棋盘，空位不可误点。沿用 Core 的存取、扩容和存档规则，满盘奖励仍按原规则进入待入盘队列。
