# 山海·栖霞 v10 修复与优化总方案（已执行）

## 验收契约

- 品牌统一为“山海·栖霞”，公开内容为 12 卷、12 兽、60 形态。
- 30 日是陪伴节奏目标，不设置阻止玩家继续推进的硬日历门。
- 首发关闭激励广告；分析默认关闭，未明确启用和配置端点时不产生用户标识或网络请求。
- 玩家可见术语以 `docs/glossary.md` 为唯一口径；内部兼容字段 `affection/heal/xp` 不改名。
- 旧素材先外部归档再移出工作区；构建、真实浏览器、视觉和发布包全部通过才算完成。

## 已完成实施

### 1. 存档与事务

- 存档升级至 schema v10：LocalStorage A/B 与 IndexedDB 镜像仲裁、revision 乐观并发、同 revision 异 checksum 冲突处理、未来版本全局只读。
- 语义无变化不再制造新 revision；普通保存不扩张历史，关键节点才写 checkpoint。
- 照料事务使用持久 token 严格绑定异兽与难度；重载退款只执行一次，成功优先，禁止重复结算。
- v9 棋盘与药匣迁移保持物品多重集，重复迁移幂等，满盘溢出进入待入盘队列。

### 2. 十二卷核心循环

- 12 卷/12 兽状态机、前三卷结局、卷八/十一故事优先路径与终卷 saga 全部可从公开 API 推进。
- 12 个岗位按 locked → ready → active 生效，奖励按日幂等。
- 生成器按 instanceId 操作；有限生成器耗尽后有永久来源兜底，消除同族误操作与软锁。
- 时间回拨重设基线；周奖励 A-B-A 不可重复；签到只发当前可达产线。
- 54 个合成图标、12 个建筑等级资源、60 张十二兽形态立绘均纳入发布门禁。

### 3. UI、触控与可访问性

- v14 适配 compact/standard/tall；320×568 至 430×932 竖屏及 844×390 横屏均可完整操作。
- 49 格归灵台、目标栏、四个快捷工具和底栏在小屏不丢失；整理、回收、药匣、配方均为真实功能。
- 弹窗具备焦点陷阱、Tab/Escape、背景 inert、关闭后焦点恢复与页面缩放支持。
- 修复庭院漫游层遮挡照料 HUD，以及 v14 隐藏选择卡后医馆、百草园、梳洗台、嬉游亭无法进入的真实触控路由；v14 建筑单击直达主操作，旧布局保留两段式兼容。
- 引导启动竞态、MutationObserver/RAF、重复监听器与失败重试均已收敛。

### 4. 美术与视觉

- gate、clinic、forecourt、groom_pavilion 保留 4×4 张真实阶段图。
- workshop、den、canteen、herb_garden、alchemy、library、playground、storage、charm_altar、cloud_isle 使用 10 张 v10 透明底图，由 CSS 表达 ruined/cleaned/repaired/restored 阶段，删除 40 张重复占位图。
- 10 张新图的生成提示词、源图路径与透明化处理记录见 `prototype/assets/art/v10/sect/GENERATED-ASSETS.md`。
- 旧 32 屏概念稿含退役品牌与信息层级，已完整外部归档；当前 32 屏真实浏览器渲染成为 canonical 回归基线。

### 5. 隐私、音频与商业化

- 分析默认 opt-out；只有显式启用且配置端点后才可发送，失败具备退避与永久失败状态。
- 音频遇到浏览器自动播放拒绝时重新上锁，等待下一次用户手势重试；失败 Promise 不污染缓存。
- 激励广告默认禁用且不触碰 provider；启用后奖励 receipt 幂等，中途关闭、失败或跳过不发奖励。

### 6. 名称与素材清理

- 统一山海·栖霞、灵阵、归灵台、药匣、暂存区、梳洗阁/梳洗台、嬉游坪/嬉游亭、医馆/医馆·药庐、信任、疗愈、宗门阅历、归灯。
- 旧入口、v13 重制层、叙事回写工具、过期测试、重复阶段图、旧 PNG/atlas、源稿中间目录与旧 release 已移出工作区。
- 生成缓存、截图、浏览器追踪、临时渲染与 Python 缓存已移出工作区；`prototype/node_modules` 保留，以便离线复跑测试。
